Relier tes réseaux

Deux façons de faire. Le mode simple prend 5 minutes. Le mode direct est gratuit mais demande de créer une « application développeur » sur chaque réseau (une seule fois).

Mode simpleYouTubeFacebook & InstagramTikTokXClé IA

Mode simple · Upload-Post

  1. Crée un compte sur upload-post.com (offre gratuite pour commencer, puis abonnement selon le volume).
  2. Menu Manage Users → crée un profil, par exemple moi.
  3. Sur ce profil, connecte TikTok, Instagram, Facebook, YouTube et X (boutons « Connect »).
  4. Menu API Keys → crée une clé et copie-la.
  5. Dans Publik : Comptes → Simple → colle la clé et le nom du profil → Tester la connexion.

Instagram et Facebook exigent un compte professionnel (créateur ou entreprise) relié à une Page Facebook. Ça se change gratuitement dans les réglages de l'app Instagram.

Mode direct · avant de commencer

Les réseaux renvoient vers ton app après la connexion : elle doit donc avoir une adresse publique en https (ex. https://publik.mondomaine.fr). Renseigne-la dans Réglages → Adresse publique. Chaque carte de l'écran Comptes affiche l'adresse de redirection exacte à copier.

YouTube

  1. Va sur console.cloud.google.com → crée un projet « Publik ».
  2. API et services → Bibliothèque → active YouTube Data API v3.
  3. Écran de consentement OAuth → type « Externe » → ajoute ton adresse Gmail comme utilisateur test.
  4. Identifiants → Créer → ID client OAuth → type « Application Web » → colle l'adresse de redirection affichée dans Publik.
  5. Copie le Client ID et le Client secret dans Publik, puis clique Connecter YouTube.

Quota gratuit : environ 6 vidéos par jour. Les vidéos verticales de moins de 3 minutes deviennent des Shorts.

Facebook & Instagram

  1. Il te faut une Page Facebook et un compte Instagram professionnel relié à cette Page.
  2. Sur developers.facebook.com → Créer une app → cas d'usage « Autre » → type « Entreprise ».
  3. Ajoute les produits Facebook Login for Business et Instagram (API Instagram avec connexion Facebook).
  4. Dans Facebook Login → Paramètres, colle l'adresse de redirection de Publik dans « URI de redirection OAuth valides ».
  5. Paramètres → Général : copie l'ID de l'app et la Clé secrète dans Publik, puis Connecter.

Tant que l'app est en mode « développement », elle fonctionne pour tes propres comptes (administrateur de l'app) : c'est suffisant pour un usage personnel.

TikTok

  1. Sur developers.tiktok.com → Manage apps → Connect an app.
  2. Ajoute les produits Login Kit et Content Posting API (active « Direct Post »).
  3. Scopes : user.info.basic et video.publish. Colle l'adresse de redirection de Publik dans Login Kit.
  4. Copie Client key et Client secret dans Publik, puis Connecter TikTok.

Tant que TikTok n'a pas audité ton app, les vidéos sont publiées en privé (tu peux ensuite les passer en public depuis l'app TikTok). Pour publier directement en public, demande l'audit depuis le portail développeur.

X (Twitter)

  1. Sur developer.x.com → crée un projet et une app (offre gratuite possible pour publier).
  2. User authentication settings → active OAuth 2.0, type « Web App », permissions Read and write.
  3. Colle l'adresse de redirection de Publik dans « Callback URI ».
  4. Copie le Client ID et le Client Secret (OAuth 2.0) dans Publik, puis Connecter.

Clé IA (facultatif, recommandé)

  1. Crée un compte sur console.anthropic.com et ajoute quelques euros de crédit.
  2. API Keys → Create key, copie la clé (sk-ant-…).
  3. Dans Publik : Réglages → Intelligence artificielle.

L'IA regarde tes images, garde les plus belles, écrit l'accroche, les sous-titres, et des légendes + hashtags adaptés à chaque réseau. Compte quelques centimes par vidéo.
