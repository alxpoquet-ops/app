# Les Minis Monstres : repères pour Claude

- Les extensions d'installation des sites clients sont gardées dans `extensions/` : `minis-site-essentiel.zip`, `minis-site-boutique.zip` (option e-commerce), `minis-site-visibilite.zip` (anciens Sites Visibilité seulement). Quand Alex en demande une, la lui envoyer telle quelle (après `python3 scripts/wp-export.py --sans-sdk` si le connecteur a changé). Mode d'emploi : `extensions/LISEZ-MOI.md`. Code : `src/wordpress/minis-site/`.
- Le site se construit avec `node build.js` ; `node scripts/check.js` doit donner 0 erreur, 0 avertissement, 0 phrase dupliquée.
- La marche à suivre pour mettre en ligne est dans `docs/gestion-du-site.md`.
- Pour créer, vérifier ou améliorer le site d'un client, suivre le skill `.claude/skills/nouveau-site/SKILL.md` (commande `/nouveau-site`) : questions d'abord, puis une étape à la fois. **Toutes les règles de création sont dans `.claude/skills/nouveau-site/regles/`** (un fichier par sujet : règles d'or, offre, visuel, conversion, Google, vitesse et accessibilité, légal, contrôle, livraison, concurrents). Une règle ne s'écrit qu'à cet endroit. L'atelier automatique lit les mêmes fichiers par `GET /aled08/v1/atelier/regles` : après un changement de règle, refaire l'export et réinstaller `aled08-espace.zip`.
- Niveau minimum d'un Site Essentiel (validé par Alex) : `docs/modeles/site-essentiel-mougiline.html`. Les règles (rien d'inventé, clair par défaut avec bouton soleil / lune, recherche de concurrents, menu téléphone avec icônes, pas de gadget non demandé…) sont détaillées dans `regles/`.
- Niveau minimum de l'option e-commerce (l'ancien Site Boutique, validé par Alex) : `docs/modeles/site-boutique-mougiline.html`. Les pages de visibilité Google achetées suivent les mêmes pages (services, pages locales, conseils), sans la boutique.
- L'offre (21 novembre 2026) : un seul site, le **Site Essentiel à 400 €**, avec l'**option e-commerce à + 200 €** (600 €). Les pages pour Google sont l'extra « Page de visibilité Google » (10 € la page, packs 1, 5 ou 10, depuis l'espace client), écrites et mises en ligne automatiquement par l'atelier. On dit « 400 € la création », et l'onglet de l'espace client s'appelle « Mes modifications ». Le Site Visibilité n'est plus proposé (gardé dans `src/config.js` avec `retire: true` pour les anciennes commandes). Forfait Mini inchangé : 10 € par mois, + 2 € si on fournit le nom de domaine.
